# plugin-stop-signal-mm

## Overview

Multimodal version of the stop signal task.

## Loading

### In browser

```html
<script src="https://unpkg.com/@jspsych-contrib/plugin-stop-signal-mm"></script>
```

### Via NPM

```
npm install @jspsych-contrib/plugin-stop-signal-mm
```

```js
import StopSignalMm from "@jspsych-contrib/plugin-stop-signal-mm";
```

## Compatibility

`@jspsych-contrib/plugin-stop-signal-mm` requires jsPsych v8.0.0 or later.
