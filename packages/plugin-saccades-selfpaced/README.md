# plugin-saccades-selfpaced

## Overview

Plugin to implement a self-paced saccades test.

## Loading

### In browser

```html
<script src="https://unpkg.com/@jspsych-contrib/plugin-saccades-selfpaced"></script>
```

### Via NPM

```
npm install @jspsych-contrib/plugin-saccades-selfpaced
```

```js
import SaccadesSelfpaced from "@jspsych-contrib/plugin-saccades-selfpaced";
```

## Compatibility

`@jspsych-contrib/plugin-saccades-selfpaced` requires jsPsych v8.0.0 or later.
